Claim Provenance — Settings

Choose which web-search providers the engine should use, and optionally bring your own API keys to bypass the operator's free-tier defaults.

More providers = more time, more rate limits. Enabled providers fan out in parallel within each claim, so latency is dominated by the slowest (typically ~3–5s), not the sum. But every provider gets one query per claim per analysis: a 7-claim article with 3 providers = 21 search requests on top of any false-untraceable retries. Free tiers get tight fast.
